LAWXYGEN NAVBAR + HERO

Files:
- index.html
- style.css
- script.js
- services-data.js
- images/lawxygen-logo.png

Open index.html using VS Code Live Server.

Search:
- Navbar search icon opens the complete service search.
- All Services opens all 236 services from the uploaded Excel list.
- Navbar dropdown service links open the search modal already filtered.
- Ctrl + K also opens search.

Login:
- Login modal is frontend-only for now.
- Backend will be connected after the UI is approved.

Easy editing:
- Colours are at the top of style.css under :root.
- Navbar and hero text are directly visible in index.html.
- All service names are inside services-data.js.
