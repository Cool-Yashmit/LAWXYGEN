# LAWXYGEN

A simple, beginner-friendly homepage project for the LAWXYGEN legal services website.

## Project files

- `index.html` — homepage structure
- `style.css` — homepage styles
- `script.js` — homepage JavaScript
- `images/` — website images and the LAWXYGEN logo
- `references/` — reference material

## Open the homepage

Open `index.html` in a web browser. No installation or build step is required.
