# LAWXYGEN Project Guide

Keep this project beginner-friendly and easy to edit by hand.

- Use plain HTML, normal CSS, and Vanilla JavaScript only.
- Keep the homepage in `index.html`.
- Keep styles in `style.css` and scripts in `script.js`.
- Store website images in `images/`.
- Store design references in `references/`.
- Do not add frameworks, build tools, backend files, or extra pages unless requested.
- Add short, helpful comments when code may not be obvious to a beginner.
